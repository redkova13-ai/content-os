# Рендер каруселей

`node render.js spec.json out_dir` превращает описание карусели (JSON) в слайды 1080×1350 PNG.

- Шаблоны: T01, T02, T03 (вёрстка из `content-os/templates/TEMPLATES.md`), палитра общая.
- Акцент: `wine`, `indigo`, `terracotta` (один на карусель).
- Типы слайдов: `cover`, `text`, `list`, `quote`, `steps`, `cta`. Неизвестный тип или шаблон даёт BLOCKED (код выхода 3).
- Фото: id из ACTIVE фотобанка (`TP-028`), необязательно `focus: [x, y]` в процентах и `zoom`.
- Текст: `**жирный**`, `*акцент*`, пустая строка = абзац. В T03 `[[текст]]` в заголовке даёт плашку‑подсветку.
- Текст сам ужимается до 72%, если не влезает (в отчёте `OVERFLOW`, код выхода 1), и подрастает до 125% на пустых слайдах.
- Рядом со слайдами пишется `render_report.json`.

Пример: `examples/sample_T02.json`. Установка: `npm ci`.
